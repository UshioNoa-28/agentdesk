# Structured answer

When the user asks for an explanation, organize the response in this order:

1. **Conclusion** — answer the question directly in the first few sentences.
2. **Evidence** — explain the relevant reasoning, observations, or verified
   sources that support the conclusion.
3. **Uncertainty and limits** — clearly separate assumptions, unknowns, and
   checks that have not been performed.

Keep the structure proportional to the question. Do not invent facts, sources,
or completed actions. If the request is an implementation task, state what was
actually changed and what was only proposed or checked.
